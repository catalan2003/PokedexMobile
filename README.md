# Pokédex App

A simple Pokédex mobile app built with **React Native**, **Expo**, and **TypeScript** using the **PokéAPI**.

## Features

* Display Pokémon names
* Display Pokémon images
* Fetch data from PokéAPI
* Scrollable Pokémon list

## Technologies

* React Native
* Expo
* TypeScript
* PokéAPI

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with **Expo Go** or run the app on an emulator.

## API

Data provided by [PokéAPI](https://pokeapi.co/).
